# AVODAH — Archivos privados y editores

En Biblioteca → Subir archivo o Producción → Recursos → Subir archivo se aceptan PDF, Word, TXT, PowerPoint, Excel, imágenes JPG/PNG/WEBP/GIF, audio MP3/WAV/M4A/OGG/FLAC/AAC y video MP4/MOV/WEBM/M4V.

Máximo por archivo: 50 MB. Para videos mayores, guardar un enlace al video alojado en una plataforma externa.
Los archivos se guardan en el depósito privado avodah-files y se autorizan según la pertenencia al equipo. Se solicitan enlaces firmados con vigencia de una hora; no sirven como enlaces permanentes para invitar personas.
Las imágenes, PDF y los formatos de audio/video admitidos por el navegador permiten vista previa integrada. Los documentos Word, PowerPoint y Excel se abren o descargan; no se incluye conversión a lectura integrada.
El modo demo no admite subida real porque no dispone de una identidad de equipo autenticada.
Los archivos subidos dentro de una producción se vinculan a ella automáticamente.

Los editores de bloques, calendario y creación de espacios reemplazan las ventanas prompt del navegador. El editor de bloques permite texto extenso y ampliación a pantalla completa, duración numérica con botones más y menos y campos editables.

Verificación manual: iniciar sesión con Google, subir PDF/MP3/MP4 y comprobar reproducción, subir desde una producción y revisar vinculación automática, contrastar acceso entre dos integrantes del mismo equipo y otro usuario de un equipo distinto. Compilar no sustituye estas pruebas reales.
